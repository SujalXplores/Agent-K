# Building a reporting dashboard

Workspace-level dashboards (Workspace Settings > Dashboards > "New dashboard") let you combine widgets pulled from multiple projects: burndown charts, cumulative flow diagrams, time-tracking summaries, and custom-field breakdowns (e.g. count of tasks by a "Priority" dropdown field).

Each widget has its own filter scope independent of the dashboard as a whole, so you can, for example, put a burndown chart for Project A next to a time-tracking summary for Project B on the same dashboard page. Widgets refresh on a 5-minute cache by default; use the manual refresh icon on a widget if you need up-to-the-second data during a live standup.

Dashboards can be set to auto-refresh in the browser (useful for displaying on an office TV) via the "Auto-refresh" toggle in dashboard settings, with an interval of 1, 5, or 15 minutes. Dashboards can also be shared via a read-only public link if you want to expose status to stakeholders without giving them a full Flowdeck seat, though this requires explicit workspace-owner approval since it creates an unauthenticated external access point.

Exporting a dashboard as a static PDF snapshot (rather than a live link) is available from the same share menu, useful for weekly status reports sent by email instead of a live link.
