# Saving a project as a reusable template

Any project can be saved as a template via Project Settings > "Save as template", which captures its columns, custom fields, automation rules, and any tasks marked as "template tasks" (regular tasks are not included by default, only ones explicitly flagged). New projects can then be created from that template instead of starting blank.

Templates are workspace-scoped, not project-scoped, so any member with permission to create projects can use a template saved by someone else in the same workspace, which is useful for standardizing recurring project types like client onboarding or sprint planning.
