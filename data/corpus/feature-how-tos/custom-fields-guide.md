# Adding and using custom fields

Project Settings > Custom Fields lets you add typed fields (text, number, dropdown, date, or person) that appear on every task in that project. Dropdown fields support up to 20 options each and can be reordered, which affects display order on the task card but not on existing task values.

Custom fields can be used as filter and group-by criteria in saved views (see saved-views-and-filters), and up to 10 per project can be mapped into the Jira two-way sync's field mapping if you're using that integration.
