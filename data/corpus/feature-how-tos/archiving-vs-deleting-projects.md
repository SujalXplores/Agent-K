# Archiving vs. deleting a project

Archiving a project (Project Settings > "Archive project") hides it from the active projects list but keeps all data intact and fully restorable at any time from Workspace Settings > Archived Projects. Deleting a project is different: it enters a 30-day soft-delete recovery window (also under Archived Projects, marked "Pending deletion"), after which it is permanently and irreversibly purged.
