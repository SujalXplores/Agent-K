# API-based integration vs. a native Flowdeck integration

Native integrations (Slack, GitHub, Jira, Google Calendar) are built and maintained by Flowdeck, configured entirely through the UI, and receive first-party support. Building against the raw API (generating your own API key and calling REST endpoints directly) gives you full flexibility but means you own the integration code, error handling, and any updates needed when Flowdeck's API changes.
