# Setting up a Zapier automation with Flowdeck

Flowdeck is listed on the Zapier app directory as both a trigger ("New Task Created", "Task Status Changed") and an action ("Create Task", "Update Task") source. Authenticate Zapier against your workspace using an API key with read-write scope, generated under Workspace Settings > Developer > API Keys.

Test the Zap with Zapier's built-in test step before turning it on - this sends one real API call against your workspace, so use a test project rather than a production one the first time you wire up a new Zap.
