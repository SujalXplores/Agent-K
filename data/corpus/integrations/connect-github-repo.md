# Linking a GitHub repository to a project

Under a project's Settings > Integrations > GitHub, click "Link repository" and authorize Flowdeck's GitHub App for the target repo (you need admin access on the repo to complete this step). Once linked, commit messages containing "Fixes FLOW-123" or "Closes FLOW-123" automatically transition that task's status to Done when the commit lands on the default branch.

You can link multiple repositories to a single project if your feature spans several services, but each repository can only be linked to one Flowdeck project at a time - linking it elsewhere first removes the prior link automatically.
