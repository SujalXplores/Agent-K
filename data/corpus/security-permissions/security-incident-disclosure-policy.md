# Flowdeck's security incident disclosure policy

In the event of a security incident affecting customer data, Flowdeck commits to notifying affected workspace owners within 72 hours of confirming the incident, via both email and an in-app banner, regardless of whether the underlying issue was already resolved by that point. Notifications include what data was affected, what actions Flowdeck has taken, and what action (if any) is recommended on the customer's side, such as rotating API keys.
