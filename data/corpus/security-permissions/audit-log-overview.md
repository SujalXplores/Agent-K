# Using the workspace audit log

Workspace Settings > Security > Audit Log (Team and Enterprise plans) records every security-relevant action: logins, permission changes, API key creation/revocation, integration connections, and project deletions, each with the acting member, timestamp, and IP address. Logs are retained for 1 year on Team and indefinitely on Enterprise, and can be exported as CSV or streamed to an external SIEM via webhook on the Enterprise plan.
