# Managing multiple workspaces under one billing account

If your organization runs several Flowdeck workspaces (for example, separate workspaces per department), you can link them under a single billing account from Workspace Settings > Billing > "Link workspaces" using an organization billing code issued by Flowdeck support.

Linked workspaces receive one consolidated monthly invoice broken out by workspace name, rather than separate invoices per workspace, which simplifies expense reporting for finance teams. Each workspace still has its own independent plan tier and seat count within the consolidated invoice.
