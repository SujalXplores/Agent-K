## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator/network → POST /admin/flags | Untrusted caller can toggle deliberately-dangerous fault injectors |
| flag state → injection points | A stuck-on flag degrades the monitored service until reset |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | POST /admin/flags | mitigate | X-Admin-Token shared-secret gate via flags.token_matches; 401 on mismatch when ADMIN_TOKEN set |
| T-03-02 | Information Disclosure | Admin-token comparison | mitigate | hmac.compare_digest (constant-time), never `==` |
| T-03-03 | Elevation of Privilege | Open endpoint when ADMIN_TOKEN unset | accept | Deliberate for local demo/eval per CONTEXT.md; document in code + runbook that ADMIN_TOKEN must be set for any beyond-localhost exposure |
| T-03-04 | Denial of Service (self-inflicted) | Flags left enabled after demo | mitigate | Unauthenticated GET /admin/flags lets an operator audit state; flags default OFF at import; reset fixture in tests |
| T-03-05 | Tampering | Route added after instrument_app | mitigate | Routes registered in main.py step 2, before instrument_app (asserted by line-order test) |
</threat_model>
