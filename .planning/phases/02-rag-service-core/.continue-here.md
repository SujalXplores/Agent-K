Project uses `postgresql+asyncpg://` (asyncpg driver), not psycopg. `pgvector.psycopg` requires the unused `psycopg` package to even import, and doesn't export `register_vector_async` regardless. | advisory | Correct API confirmed by inspecting the installed package: `from pgvector.asyncpg import register_vector`, called as `dbapi_connection.run_async(register_vector)` inside the `event.listens_for(engine.sync_engine, "connect")` handler.
