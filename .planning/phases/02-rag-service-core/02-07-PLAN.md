### HV-1 — SC-4 / RAG-04: each provider actually SERVES a request

**Why a human:** no provider credential exists in this environment, so no live third-party call can be made or guessed. Client *construction* is already proven programmatically for all three providers (correct `base_url`, correct model, correct `{PROVIDER}_API_KEY` lookup, `KeyError` on an unknown provider, and after Task 1 a hard failure on a missing key). What remains unproven is that each provider genuinely serves a request.

**Steps:**
1. Put a real `GROQ_API_KEY` in `.env` and start the service (`uvicorn app.main:app`) with the seeded `rag-postgres` container running.
2. `POST /ask` with a question the corpus covers (for example, rotating an API key). Confirm a real, grounded answer returns with a `sources` array.
3. Open the `chat` span and confirm `gen_ai.system` / `agentk.llm.provider` say `groq` and `gen_ai.response.model` is a Groq model family id.
