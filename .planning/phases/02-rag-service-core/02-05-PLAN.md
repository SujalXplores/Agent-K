Root cause (02-VERIFICATION.md, Anti-Patterns table + Key Link "BROKEN" row):
  app/models.py:30 declares  embedding: Mapped[list[float]] = mapped_column(Vector(EMBEDDING_DIM), nullable=False)
  using pgvector.sqlalchemy.Vector. That type's bind processor already serializes a Python list into
  the Postgres text form '[...]'. app/db.py additionally registers the pgvector asyncpg codec on every
  new connection, and that codec rejects the already-serialized string because it expects a list/ndarray.
  The two registration paths are mutually exclusive. Keep the ORM type (app/models.py and app/rag.py
  both depend on it); drop the connection-level one.
