<objective>
Author the synthetic support-doc corpus and the idempotent seed script that loads it into pgvector with locally-computed embeddings (RAG-02). The corpus is a fictional generic B2B SaaS product's support docs across six topic areas (D-01), with deliberate length variety from one-paragraph FAQs to multi-paragraph troubleshooting guides (D-02).

Purpose: The `/ask` retrieval step in 02-04 needs real, varied documents to search over; and Phase 3's retrieval-latency and prompt-regression failure scenarios need visibly non-trivial retrieval/generation behavior, which uniform tiny docs would not provide (D-02). Embeddings must be computed locally — no external embedding API — satisfying the zero-budget/no-embedding-API constraint (RAG-02).

Output: `data/corpus/` (the authored docs), `scripts/seed_corpus.py`, and a seeded `documents` table with 50-200 rows carrying non-null embeddings. Depends on 02-01 (the live documents table + app/embeddings.py must exist).
</objective>
