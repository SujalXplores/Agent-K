<objective>
Build the minimal, reusable FastAPI skeleton with OpenTelemetry dual-exporter instrumentation (console + OTLP-HTTP, always on) that later phases extend. This is the code half of TELE-03: a real scaffold (D-04) — `app/main.py` + `app/telemetry.py` with correct OTel wiring — not a throwaway smoke script, and with no `/ask` or RAG logic yet (D-05). Console and OTLP exporters run simultaneously with no toggle (D-06), and the OTLP exporter uses HTTP/protobuf on port 4318, never gRPC (D-07).

Purpose: Establishes the first project code patterns (OTel provider setup, exporter configuration, instrumentation ordering) that Phase 2 imports and builds on without re-wiring. Proves the skeleton emits spans locally (console) before SigNoz-side delivery is verified in plan 01-03.

Output: `app/telemetry.py`, `app/main.py`, `app/__init__.py`, `requirements.txt`, `.env.example`, updated `.gitignore`.
