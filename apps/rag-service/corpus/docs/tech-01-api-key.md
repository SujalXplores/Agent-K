# How do I get an API key?

To get an API key, go to Settings > Developer > API Keys. Click "Generate New Key" and give it a name (e.g., "Production App"). Your API key will be displayed once — copy it immediately as it won't be shown again. API keys are scoped to your account and have rate limits of 1000 requests per minute. Keep your API key secret — do not commit it to version control or expose it in client-side code. You can revoke a key at any time.
