# What do the API error codes mean?

Common API error codes: 400 Bad Request — your request body or parameters are malformed. 401 Unauthorized — your API key is missing or invalid. 403 Forbidden — your API key doesn't have permission for this resource. 404 Not Found — the requested resource doesn't exist. 429 Too Many Requests — you've exceeded your rate limit. 500 Internal Server Error — something went wrong on our side. 503 Service Unavailable — we're temporarily down for maintenance. All error responses include an error code and message.
