# How do I enable dark mode?

Dark mode is available on all plans. To enable it, go to Settings > Appearance > Theme and select "Dark." You can also choose "System" to automatically match your operating system's dark mode setting. Dark mode applies to the web app, mobile app, and email notifications. If you're using the API, you can set the theme per-user via the /api/v1/users/me/preferences endpoint with the ``theme`` parameter set to "dark" or "light".
