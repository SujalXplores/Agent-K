# How do I set up automation rules?

Automation rules let you trigger actions based on events. Go to Settings > Automation > Add Rule. Define a trigger (e.g., "when an item is created") and one or more actions (e.g., "assign to user," "send email," "set custom field"). Rules can have conditions (e.g., "only if category is 'technical'"). Rules are evaluated in order and can be enabled/disabled individually. Enterprise plans support multi-step rules with delays and conditional branching.
