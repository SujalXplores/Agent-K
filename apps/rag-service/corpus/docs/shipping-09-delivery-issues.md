# What if my package is lost in transit?

If your package hasn't arrived within the expected delivery window plus 3 business days, contact support with your order number. We'll file a claim with the carrier and initiate an investigation. If the carrier confirms the package is lost, we'll send a replacement or issue a full refund — your choice. Investigations typically take 5-7 business days. If the package is found after a replacement has been sent, we'll arrange for the original package to be returned.
